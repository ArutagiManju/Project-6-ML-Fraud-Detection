**Project.6. ML Classification & Clustering: Fraud Detection & Customer Segmentation**

**Project Overview**
Combine classification and clustering techniques to detect fraudulent transactions and
segment customers for targeted strategies. This capstone project synthesizes machine
learning fundamentals with domain knowledge.

**Learning Objectives**
 Handle imbalanced classification problems (fraud datasets)
 Train and compare classification models (Logistic Regression, Random Forest,
XGBoost)
 Evaluate using metrics suited to imbalanced data (precision, recall, F1, ROC-AUC)
 Apply unsupervised clustering (K-Means, Hierarchical) for customer segments
 Interpret and action model predictions
 Optimize for business trade-offs (false positives vs negatives)

**Dataset Information**

**Project A: Fraud Detection**
Data Link: Kaggle - Credit Card Fraud
Target: Class (Binary: 0=Legitimate, 1=Fraudulent) — typically imbalanced (~0.1% fraud
rate)

**Project B: Customer Segmentation**
Data Link: Kaggle - Customer Clustering or Mall Customer Segmentation
No explicit target (unsupervised; used for business segmentation)

Phase 1: Fraud Detection - Data Preparation

Phase 2: Train & Compare Classification Models

Phase 3: Optimize Fraud Detection Threshold

Phase 4: Customer Segmentation with Clustering

Phase 5: Visualizations & Actionable Insights

**Tools & Libraries**
Python, Pandas, NumPy, Scikit-learn, XGBoost, SMOTE (imbalanced-learn), Matplotlib,
Seaborn
